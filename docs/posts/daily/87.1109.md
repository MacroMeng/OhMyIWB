> **警告** 本文包含了大量个人情感与判断，请理性看待！

大家晚上好。本来我不想在期中考试第一天晚上写 OMI 的。

起因是这个 B 站视频所描述的输入法激起了我的兴趣：

https://www.bilibili.com/video/BV1Z8xA6zEpD/

我试用了它（详细评论可以前往 https://mm666.qzz.io/blog/CyIME-is-good-but-not 查看，CC-BY 4），结果是：好是好，但平衡性仍然是亟需解决的问题。于是我去它的 GitHub Repo 交了 2 个 Issue，#183 和 #202，您猜怎么着？它被完全地拒绝了，Comment 明晃晃地写着 *Generated by Claude Code*。

Callback：「【CyIME】别再 vibe coding 输入法了｜我做了世界上最好的Android开源输入法  杀死比赛的那种」

现在谁才是 Vibe 了输入法的那个人？我想大家心里都有数了，AI 风味过头的文案与敷衍的 GitHub 回复都很好的回答了这个问题。回复里写着「冻结功能」？一个新输入法这么快就不做 Feature 了？我看 CI 都一直在推 Android 适配也没见它封锁所有 Feature Request 啊。

再回过头来看它 B 站视频简介：（原文如此）

> 相信在座的各位最近看过不少vibe coding的输入法了
>
> 里面有大量我个人的偏好和执着, 不一定符合你口味, 符合我的就行. 我是个独断的人, 我认为有些功能就是没用的, 这个地方就应该这样, 那个地方就应该那样... 而正是这些独到的品味才能让我做出一套逻辑足够自洽的作品. 
> 
> 其中还有大量细节十分推荐各位尝试和对比, 欢迎锐评, 欢迎拉踩, 不服就来比划两下, 写好脚本做个实机演示, 用实际体验说话. 
> 
> ……
>
> 但我为什么敢说自己是世界上最好的, 那是因为竞争对手实在太垃圾了...你们赶紧来抄我的优秀设计, 抄好了对大家都有好处, 不过抄了记得挂GPLv3, 这是上游项目就强制的, 不过我也知道有些人喜欢用ai洗来洗去的，无所谓了, 只要能提高整个社会的效率, why not

我并不是说这个输入法不好，我在我的博客里也明确表示了它确实是综合体验很好的输入法。但就它五十步笑百步这种行为来说，我就会决定卸载掉它用回我的 Fcitx5.Fx，说实话手感也没那么差。但它的实际体验真的好吗？诸位自己评判。

别拿 AI 代替自己的脑子思考，不然智械危机了你会是第一个被取代的。
