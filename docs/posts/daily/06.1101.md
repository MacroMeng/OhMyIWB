Better DeepSeek 是一个面向 DeepSeek Chat 网页端的开源浏览器扩展。它为 DS 网页版添加了许多**原本应提供**的功能，比如像 GPT 一样的图标生成渲染等等。

https://github.com/EdgeTypE/better-deepseek BDS 在 GitHub 上开源。

## 功能

**工具标签：对话里直接产出文件**

Better DeepSeek 注入了一组扩展标签。在对话中触发这些标签，DeepSeek 的回复会变成可下载的产物，而不是一段需要手动复制粘贴的文本。支持的范围包括 PowerPoint（.pptx）、Excel（.xlsx）、Word（.docx），以及可以直接在对话中预览的 HTML。图表、可视化模拟和 MIDI 音频也能以标签形式生成。

**持久记忆与角色、技能、项目**

扩展会把对话中出现的偏好、技术栈和进行中的项目记录为记忆，在后续对话中继续生效。用户也可以创建角色、技能、项目，扩展会自动保存并激活，之后一键切换。

**浏览器内代码执行**

包括 Python 等在内的语言都可以在浏览器里直接运行。它也扩展了原有的代码框功能，使之可以下载文件。

**语音模式**

支持语音输入提示词和语音朗读回复，~~这下你可以和大肥鱼打电话了~~
