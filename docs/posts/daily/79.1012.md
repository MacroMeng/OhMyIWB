**[Manim](https://www.manim.community/) 是一个用于创作数学动画的 Python 库。**你可能在 B 站上许多 Up 主的视频里见过这种视频风格，流畅美观的公式/文本显隐、直观的数学可视化过程……这些都是 Manim 的功劳。

目前 Manim 最通用的版本是 Manim Community Edition，也就是上面所给到的超链接。

Manim 支持 Typst 和 LaTeX 的公式渲染，当然你先要在对应的系统上预先安装好这些软件。比如对于 Windows，MikTex 就是很好的 LaTeX 发行版选择。

> Manim 的公式渲染默认用的似乎是 pdflatex 库，对中文支持堪忧。你可以通过更改配置改到支持更好的 xelatex 渲染器。

Manim 推荐使用 uv 作为环境管理，关于 uv OMI 之前已经介绍过，不再赘述；你只需要新建一个 uv 虚拟环境，再像平常一样使用 `uv add manim` 就可以开始使用 Manim 了。

现在你可以通过这条命令初始化 Manim 项目（包含所有 Manim 所需文件）：

```bash
uv run manim init project my-project --default
```

（将 my-project 替换成你项目的名称。）

要渲染 Manim 脚本到视频，使用：

```bash
uv manim -pql main.py CreateCircle
```

替换 main.py 到你的脚本名称，CreateCircle 到你的 Scene 子类即可。

Manim 会把输出放在 media 目录下。这有一些常用的命令行参数供你参考：

- `p` 渲染完成后播放
- `q[X]` 控制质量，比如 `[X]` = `l` 即为 480p15fps，`h` 为 1080p60fps。

你可以去 Manim [官方文档库](https://docs.manim.community)查看更多信息。
