**今日截至发稿约 5h 前，PCL 官方版的 Minecraft 核心（或称实例）下载渠道已不可用。旧版本 PCL 似乎仍然可用。** HMCL 主要维护者也称可能会移除 HMCL 的 MC 下载功能；其他启动器暂未有官方公告。

若你目前想要下载 Minecraft，你可以使用 BakaXL 4 测试版、PCL CE 等启动器。或者，你也可以使用国外的 Prism Launcher 等启动器；官方启动器亦可。Fabric、[Neo]Forge 加载器、CurseForge、Modrinth 平台暂未受影响；国内 BMCL API 下载源貌似仍然可用，大概只是启动器层面的封禁。（需要确认）

[AWARNING] 千万不要下载来路不明的 exe 文件！它们可能包含病毒与木马。请始终从各个启动器官方下载渠道下载启动器。 [/AWARNING]

目前比较广泛的来源是，某位家长看见小孩在玩含有 [数据删除] 的 Minecraft 游戏，遂将其举报，不知怎么也一同举报了启动器造成了功能的禁用。目前此功能恢复时间暂未有明确说明。
