> ~~往日种种，你不记得了吗——~~

想必各位用大屏时肯定会换一些恒河意味的壁纸（不是错别字）。如果你不想让他人在「设置」中见到历史壁纸，可以这么干：（我们推荐换教室时也执行这个操作，我因为它看到了上届班级留下的阴间大头照……）

1. 打开注册表编辑器（`regedit.exe`）。
2. 定位到 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Wallpapers`。
3. 删除 `BackgroundHistoryPathX`（`X` 对应数字），或将值设为 `-`。

如果是锁屏背景，也可以删除，如下操作：

1. 定位到 `C:\ProgramData\Microsoft\Windows\SystemData\S-1-5-...\ReadOnly`。
2. 删除 `LockScreen_X` 文件夹。你可以打开文件夹确认里面的图片（可能需要提权）。

将以上两个项目删除后，原位置会被替换为 Windows 默认图片。
