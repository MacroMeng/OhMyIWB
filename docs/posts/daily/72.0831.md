欢迎体验全新的OMI主题啊~这里是MKStoler1024。

容我向您介绍今天为了OhMyIWB全新>!Vibe!<出来的主题，[Kratos for VitePress](https://github.com/MKStoler1024/kratos-vitepress)！

<!-- more -->

一款参考 [Kratos WordPress 主题](https://github.com/seatonjiang/kratos) 设计风格从零实现的 **VitePress 博客主题**。

删繁就简，专注于用户的阅读体验。

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建生产版本
npm run build

# 本地预览
npm run preview
```

## 项目结构

```text
kratos-vitepress/
├── docs/                          # 站点目录
│   ├── .vitepress/
│   │   ├── config.mjs             # 站点与主题配置
│   │   └── theme/                 # 自定义主题
│   │       ├── index.js           # 主题入口
│   │       ├── Layout.vue         # 主布局
│   │       ├── composables/       # 数据加载
│   │       ├── components/        # 主题组件
│   │       └── styles/            # 主题样式
│   ├── public/                    # 静态资源
│   ├── index.md                   # 首页（layout: home）
│   ├── about.md                   # 关于页
│   ├── 404.md                     # 404 页
│   └── posts/                     # 文章目录（自动抓取）
└── package.json
```
