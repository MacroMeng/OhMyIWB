GitHub 禁止新用户使用 Outlook 和 Hotmail 邮箱注册新账号。众所周知 Outlook 邮箱注册一直以来都十分简单，连手机号都不需要，只需要过一遍人机检测就能拿到一个邮箱。为了防止灰产滥用，GitHub 已经禁止了 Outlook 邮箱注册，已注册的账号（~~比如我~~）不受影响。
