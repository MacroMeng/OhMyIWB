如你所见，现在访问 [OMI 官网](https://ohmyiwb.mm666.qzz.io/)，你将会看到一个船新的面孔，构建自 VitePress 与 Teek 主题，此外还要感谢 MKStoler 的大力智齿🌹

以下还有一些更详细的更改与说明：
- RSS 可以知道本篇 OMI 作者了！虽然 OMI 迄今为止的 3 个作者文风都有很大不同，但是有这个功能，自然是极好的。
  如果你想写作，只需要像这篇文章的 Frontmatter 一样把 `author` 字段改成你的名字就好啦。
- 更多变的主题。网页端外观大更新，使用了 Google Sans Flex / Noto Sans SC 作为主要无衬线字体；尚古明体（作为一种旧字型字体）作为阅读字体（如果你不喜欢这类字体想要更正常的 Noto Serif，请跟帖告诉我（））；Maple Mono NF CN 作为等宽字体。
  同时主页的背景、Logo 等元素也用上了新设计，当然还有——
  **OMI 紫！** 我当时没想到要直接命名，不过感谢 Q 群 @CoolMount 提出了这一名称：#6815CF！这是 OMI 新官网的主题色调。
- 感谢 MKStoler 制作的卡片目录页！原来直接用主题的话 Daily 和 Thinklog 的目录页会十分眼瞎，MKStoler 制作了这一卡片页面让显示效果更加舒适，此外还有其他优化。
- 新的错别字反馈方式！OMI 错别字是老传统了，如果你热衷于找错别字那你可 _找对地方了_ ，前往 [OMI GitHub 仓库 - Issues](https://github.com/MacroMeng/OhMyIWB/issues) 就能看到船新的 Typo Issue 模板。 ~~刷 GitHub 贡献的好方式！~~
